FAQ

Is my data private?

Yes. Finder runs locally, indexes on-device, and never sends your file list anywhere. The source is private; only installers are public.

Does it need admin?

Installer can run per-user without admin. For fastest file indexing it will prompt once for admin to read the NTFS journal.

How do updates work?

The app checks the public releases feed. When a new version is available you’ll see an in-app banner.
