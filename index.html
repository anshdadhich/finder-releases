Capabilities

Engineered for pure speed.

No indexing bloat, no memory hogging. Instant response right from your keystrokes.

Find Any App in a Second

Press Ctrl+Space, type a few letters, hit Enter. No Start menu hunting or lagging animations.

spot → Spotify.exe

Find Any File, No Matter How Deep

Just type the end of the path like Finder\logo.png and Finder locates it even if it's buried deep inside subfolders. You never need full paths.

Finder\logo.png

Go Anywhere Directly

Paste full paths like C:\Users\..., network shares \\server\share, or shortcuts like ~ and %TEMP% to open immediately.

Calculator Built In

Type 12*7 or (3+4)*9 and the calculated answer appears on top. Hit Enter to copy it to your clipboard instantly.

Search the Web

Type @ followed by your query, like @weather, and press Enter to instantly search Bing or your default engine.
